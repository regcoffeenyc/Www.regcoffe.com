## 4. „თუ X → მაშინ Y" პლეიბუქები (დაიზეპირეთ ეს 6)

1. **რეგულირებადი ნივთი გამოჩნდა კანონიერებაში** → არასდროს დაამტკიცოთ სამივე პუნქტის რეალური გადამოწმების გარეშე. ეჭვისას — უარყოფა.
2. **უარყოფითი კომენტარი სოც. ქსელში** → პასუხი 24 საათში, თავაზიანად, ფაქტებით. არასდროს წაშალოთ კრიტიკა (სპამის გარდა).
3. **მარაგი ≤2** → ან შეავსეთ, ან გამორთეთ პროდუქტი. ნახევრად ცარიელი ვიტრინა ნდობას კარგავს.
4. **შეტყობინება 2+ დღეა უპასუხოა (follow-up ნიშანი)** → ეს პირველ რიგში, ბრიფინგშიც ზემოთ ამოვა.
5. **საეჭვო გამყიდველი** (ყალბი ფოტო, არარეალური ფასი) → ბლოკი + განცხადების უარყოფა. ჯერ დაბლოკეთ, მერე გაარკვიეთ.
6. **ახალი აქცია დაიწყეთ** → პრ აგენტიდან UTM ბმულით გააზიარეთ ყველა არხზე — ისე გეცოდინებათ, საიდან მოვიდა შედეგი.
